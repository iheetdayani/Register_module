# Register_module
C# Windows Forms app demonstrating data transfer between forms with emoji-based checkbox status display.
🖥️ C# Windows Forms – Two Form Data Transfer App
📌 Project Description

This is a C# Windows Forms Application that demonstrates data transfer between two forms.

Form 1

Accepts user input through text boxes and checkboxes

Form 2

Displays the data received from Form 1

Shows checkbox selection status using emojis

✅ Checkbox Emoji Representation

❌ Unchecked → ❌ (X Emoji)

✅ Checked → ✅ (Tick Emoji)

This approach improves readability and user experience by visually representing checkbox states.

🛠️ Features

Multi-form Windows Forms application

Passing data from one form to another

Checkbox state handling

Emoji-based status display

Simple and clean UI logic

💡 Concepts Used

C# (.NET)

Windows Forms (WinForms)

Event handling

Form navigation

Conditional rendering
